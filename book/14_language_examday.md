# Chapter 14: Language Power & Exam Day

## 14.1 Grammar for Band 7 (the 12 rules that matter most)

1. **Every sentence needs a main verb.** Fragments (*Because pollution is bad.*) and run-ons (*Pollution is bad it kills fish.*) are instant GRA damage.
2. **Subject–verb agreement:** *The number of cars has risen* (singular subject); *A number of people are...*; *Neither policy works*; data = plural (*data show*).
3. **Articles:** *the* internet/environment/government (unique systems); *a/an* first mention → *the* after; zero article for general plurals (*Pollution harms health*) and abstract nouns (*Education matters*).
4. **Countable/uncountable:** *research, evidence, information, advice, knowledge, traffic, homework, accommodation* are uncountable (no -s, no "a"): *a piece of advice, much traffic.*
5. **Tense consistency:** past-dated visuals → past simple; timeless truths → present simple; *since 1990 → present perfect*; *by 2030 → future perfect (will have...).*
6. **Conditionals:** Type 1 (*If governments invest, congestion will fall*); Type 2 (*If hours were cut, wellbeing would rise*); Type 3 (*If the law had passed, emissions would have fallen*); mixed for nuance.
7. **Passive voice:** processes (*is harvested, are dried*), formal emphasis (*It is widely believed that...*), unknown agents (*The law was repealed in 2019*).
8. **Relative clauses:** defining (*Policies that ignore costs fail*) vs non-defining (*Singapore, which introduced charging in 1975, ...* — commas!).
9. **Reported structures:** *It is argued/claimed/estimated that...; There is growing evidence that...; Critics contend that...*
10. **Comparison:** *twice as high as; by far the largest; significantly/marginally higher; compared with/to; in contrast to; outnumber.*
11. **Prepositions after key words:** *increase/rise/fall/drop IN; range FROM...TO; responsible FOR; similar TO; different FROM; depend ON; succeed IN; result IN (effect) / result FROM (cause); account FOR; in favour OF; regardless OF.*
12. **Word formation:** *economy (n) → economic (adj, of economy) → economical (adj, thrifty); effect (n) → affect (v); practice (n) → practise (v, BrE); advice (n) → advise (v).*

> Drill: error-hunt 3 of your own essays with this 12-point checklist, fixing every violation. Recurring violation = your personal grammar syllabus.

## 14.5 Idioms & Phrasal Verbs for Speaking (Band 7+ flavour — use sparingly!)

## 14.7 Computer-Delivered Tactics

1. **Listening:** no 10-minute transfer — type answers as you listen; use the 2 minutes to fix spelling/plurals. Practise typing numbers fast (phone/postcode formats).
2. **Reading:** highlight + note tools exist — use highlight for keyword zones only (over-highlighting = re-reading). Copy-paste is disabled for answers; drag-and-drop for matching is enabled — practise it.
3. **Writing:** word counter visible — still plan on the provided paper; type at 30+ wpm or choose paper. Learn: no spellcheck (don't rely on red underlines — there are none!), paragraph with Enter + blank line, cut/paste to reorder sentences.
4. **All modules:** request noise-cancelling headphones; adjust screen brightness; raise hand for any technical glitch (time is paused/documented).

## 14.8 The Final Week & Exam Day

**7 days before:** two full mocks (exam timing, no pauses); error-log review; confirm test venue, time, ID requirements; prepare route + backup route.

**3 days before:** light review only (vocabulary notebook, linker lists, your best essay); sleep 8 hours; no new strategies.

**The night before:** pack ID (passport/national ID as registered), printed confirmation, pencils + eraser + sharpener (paper), water (clear bottle, label removed where required), snack for after; set two alarms; sleep.

**Exam day timeline:**

| When | Action |
|---|---|
| Arrival (−45 min) | Register, store belongings, toilet, find room, breathe |
| Listening | Read ahead relentlessly; guess every blank; transfer carefully (paper) |
| Reading | Survey → easy-first order → 1 min/question → never blank |
| Writing | Count words; plan both tasks; Task 2 gets 40 min even if Task 1 overruns — switch on schedule |
| Between modules | Stand, stretch, water, reset mentally — never replay old sections |
| Speaking | Smile, eye contact, 2–4 sentence Part 1 answers, full 2-min Part 2, OREC Part 3; ask for repetition if needed |

**Mindset rules:** the examiner is not your enemy — they want rateable language, so give them quantity; one bad section never decides the test — reset instantly; easy questions and hard questions pay the same mark — collect easy ones first.

## 14.9 After the Test: Results, EOR, Retakes

- Results: computer 1–2 days, paper 3–5 days (online preview; paper Test Report Form follows).
- Missed by 0.5 in Writing/Speaking? Consider Enquiry on Results within 6 weeks (fee refunded if changed).
- One module short? Ask your centre about One Skill Retake (available for many computer-delivered tests, within 60 days).
- Retaking? Diagnose precisely (which criterion? which question type?) before rebooking — same preparation gives same scores. Targeted repair beats repetition.
